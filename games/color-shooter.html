Color Shooter

PlayTable · Cooperative fine motor skills game

Color Shooter is a cooperative fine motor skills game for ages 4 and up, on the PlayTable, Playmove's interactive table. Up to four players each command a ship that can only hit targets of its own color, so they have to coordinate to clear the board. Across 30 levels, the team or player that eliminates every target in the least time tops the scoreboard.

I took part in every stage of Color Shooter, as the only game designer in a team of three. The game is still available today.

My contributions

  • Concept and core mechanicI conceived the game and defined its core loop: each ship can only eliminate targets of its own color, and a wrong shot regenerates the targets, turning every mistake into a cost for the whole group.
  • Cooperative designI designed the interdependence for up to four players, each commanding one ship, so that no one can clear the board alone and the table has to coordinate who hits what, and when.
  • Scoring and competitionI defined the scoring around time, so the game works both for teams and for individual players: whoever eliminates every target the fastest tops the scoreboard.
  • Level designI designed the 30 levels in increasing order of difficulty, deciding in which level each new mechanic and obstacle enters, so that every stretch of the game brings something new to learn.
  • Mechanic variationI built new challenges by reworking existing mechanics instead of creating new ones, as with the armored obstacles, whose rules changed as the levels advanced.
  • Design within budgetI made design decisions with development cost in mind, favoring solutions that reuse assets and systems already built and that need few iterations to become a new challenge.
  • Audience and fine motor skillsI designed the interactions for the PlayTable around fine motor skills and for players aged 4 and up.
  • End to endI took part in every stage of development, from concept to the finished levels, working with an artist and a programmer.

Challenges & solutions

Cooperation built into the core mechanic

Putting four players at the same table does not make a game cooperative if each one can play alone. The decision was to tie each ship to a color: no player can clear the board on their own, so the group depends on each other to hit the right targets. A wrong shot regenerates the targets, which means speed only pays off when paired with coordination.

A 30-level sequence that does not feel repetitive

With a single core mechanic, thirty levels can easily feel like the same level repeated. The difficulty rises gradually, but the main lever of the sequence was the order in which mechanics are introduced: each new element changes how players have to coordinate, which keeps the progression fresh without breaking the rules already learned.

Budget as a design constraint

New mechanics cost development time and budget, so the design started from reusing what already existed in different ways. Armored obstacles show the process: first they were simply armored; then armored only for certain players; and later armored obstacles that can only be eliminated with shots in the right order. Each version reuses the same principle, and with few iterations the challenge it creates for the players is a different one.

Results

Color Shooter performed very well, especially within the platform's children's entertainment and education segment. The game remains available on the PlayTable today.

In this game, a single mechanic, reworked with care, was enough to carry 30 levels.
